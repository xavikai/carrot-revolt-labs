Same squares, same sharpness.

Texel density is how many pixels of texture cover one metre of surface. See it with a checker map, compute it in px/m, match it with S, Average Islands Scale, Pack Islands and Set TD as in Blender, choose a target from the camera and the memory, and learn when to break the rule.

    KEY IDEAS

    Pixels per metre

    Three things decide the density together. Change any of them and the checker squares change size.

    Texel density
    The texture pixels that a 1 m ruler on the surface covers (px/m). It is measured on the model: texture size, UV size and object size. The camera does not change it.
    The formula
    Texture size × √(UV area ÷ 3D area). For a square island: island px ÷ face m.
    Checker map
    Every square is the same number of texels: same square size = same density.
    Target
    The density you aim for, chosen per project from how close the camera gets (how big things look on screen) and the memory: about 512 px/m for third person, 1024 px/m for first person.
    Texture size
    ≈ target × size of the object in metres, rounded up to a power of two.
    Memory
    2 × the density = 4 × the pixels. A 2K texture costs four times a 1K.
    BACK IN BLENDER

    Texel density in Blender

    Blender measures UVs but has no texel density number of its own; add-ons such as Texel Density Checker add it. The rest is ordinary UV editing.

    1. Make a checker: Image › New, Generated Type Color Grid or UV Grid, at the size of your real texture. Show it in the UV Editor and in the material.
    2. Apply the scale of your objects first: Ctrl A › Scale in the 3D Viewport.
    3. In the UV Editor: UV › Average Islands Scale (Ctrl A) evens the islands of an object, UV › Pack Islands fills the square with a margin.
    4. With Texel Density Checker (N panel): set the texture size, read the density, type the target and press Set TD.
    5. Scale islands by hand with S for exceptions: hero areas up, hidden faces down.
    6. Write the target in the art bible of the project, with the texture sizes it gives for common object sizes.
