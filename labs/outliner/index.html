The Outliner, in depth.

A small game level, made in a hurry. Put it in order with the Outliner: collections inside collections, objects linked to two collections, collection instances, what is hidden, excluded or kept out of the render, what can be clicked, filters and search, and the Blender File and Unused Data views to clean the data inside the file.

    KEY IDEAS

    What the Outliner shows

    The Outliner is a list of everything in the file, seen in different ways. View Layer shows the scene as collections and objects; Blender File shows every data-block by type; Unused Data shows what nothing uses any more. Each row can be selected, renamed, dragged, hidden or right-clicked.

    Collection
    A group of objects (and of other collections). An object can be in several collections at once: moving (M) takes it out of the others, linking (Shift M) adds one more.
    Checkbox
    Exclude from View Layer: the collection is not drawn, not rendered and not even evaluated.
    Eye / Monitor
    Hide in Viewport (this view layer, temporary) and Disable in Viewports (everywhere). Neither affects the render.
    Camera
    Disable in Renders: visible while you work, never in F12.
    Arrow
    Selectable: off, clicks in the viewport go through the object.
    Instance
    An Empty that draws a whole collection at its place. Edit the collection and every instance follows.
    Users
    How many things use a data-block. At 0 it is Unused Data; a Fake User (shield) keeps it anyway.
    Filter
    The funnel: which toggles to show, which object types and states to list, and whether to list the data inside objects.
    IN BLENDER

    Outliner shortcuts

    With the mouse over the Outliner. The names are the ones of Blender 4.x.

    1. Click selects, Ctrl click adds, Shift click selects a range, double click or F2 renames, A / Alt A select and deselect all.
    2. M Move to Collection, Shift M Link to Collection; drag moves, Ctrl drag links. Right-click › New Collection makes one inside the active collection.
    3. Ctrl click on an eye isolates that collection; Shift click acts on the collection and everything inside it. H hides the selection, Alt H shows everything.
    4. Ctrl F search, Alt F clear the search. The funnel opens the filters and the Restriction Toggles (Selectable, Disable in Viewports, Holdout…).
    5. Add › Collection Instance or right-click a collection › Instance to Scene: at the 3D cursor.
    6. Display Mode Blender File: right-click › Remap Users. Unused Data › Purge (File › Clean Up › Purge Unused Data does the same).
