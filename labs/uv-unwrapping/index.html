Cut the seams. See the map.

A UV map tells a flat image where to go on a 3D model. Read it, mark seams and unwrap a cube and a cylinder, see why a closed object cannot unwrap without cuts, use Project from View, Cylinder and Sphere Projection, and tidy up with Smart UV Project, Pack Islands and Average Islands Scale.     KEY IDEAS

    From 3D to flat

    A UV map is a flat copy of the surface. Seams say where it may split; unwrapping and projections decide the shape of each piece on the image.

    U, V
    The two coordinates of the image: U across, V up, both from 0 to 1. Every corner of every face has its own pair.
    UV island
    A group of faces that stay joined on the image. A seam edge appears twice, once on each island border.
    Seam
    An edge where the surface may split when you unwrap. Red in the 3D Viewport. It does not change the model.
    Unwrap
    Flattens the selected faces with as little stretch as possible, cut at the seams. A closed island cannot be solved.
    Projection
    Sends the image onto the faces from a direction: the view, a box, a cylinder or a sphere. No seams needed, some stretch.
    Stretch
    How much the image is squashed on a face. Display Stretch colours it: blue none, red a lot.
    Pack · Average
    Pack Islands places the islands in the square without overlaps. Average Islands Scale gives them the same pixels per metre.
    0–1 square
    The image. UVs outside it repeat the texture (tiling); for painted or baked textures keep everything inside.
    BACK IN BLENDER

    The same steps in Blender

    The lab is a simplified copy of the UV Editing workspace: the menus, keys and panels have the same names. Blender has more options; these are the ones to know first.

    1. Open the UV Editing workspace tab. The object enters Edit Mode; the UV Editor shows the UVs of the selected faces.
    2. Seams: Edge select, Alt click for loops, then U › Mark Seam (also in Ctrl E). Clear Seam removes them.
    3. A and U: the menu has three unwraps, Unwrap Angle Based, Unwrap Conformal and Unwrap Minimum Stretch. In this lab the first two use the same conformal solver; Minimum Stretch adds a correction that evens out the area.
    4. Projections: U › Smart UV Project, Cube, Cylinder, Sphere Projection, Project from View. After each one, open Adjust Last Operation (bottom left, or F9) for Direction, Angle Limit, Margin…
    5. In the UV Editor: UV › Pack Islands (Ctrl P) and Average Islands Scale (Ctrl A). The Overlays popover has Display Stretch.
    6. Scaled the object? Ctrl A › Scale in Object Mode before unwrapping. To check the result, add an image with Image › New, Generated Type Color Grid.
