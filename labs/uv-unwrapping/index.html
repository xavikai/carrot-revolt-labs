When the UVs don't match the model

Someone stretched the cube in Object Mode (Scale X = 2) and unwrapped it. The UV islands are still squares, so the checker looks stretched on the model. Blender warns: “Object has non-uniform scale…”

  1. Tab to Object Mode.
  2. CtrlA › Scale. The Transform panel goes back to 1, 1, 1 but the cube keeps its shape.
  3. The UVs are now out of date. Tab › U › Unwrap.
  4. Check: square checker, and Unfold matches the model again.

BACK IN BLENDER

The same steps in Blender

This lab uses rectangular paper nets so each operation is easy to see. Blender's real Unwrap uses more advanced solvers on curved meshes and only unwraps the faces you select.

  1. Open the UV Editing workspace. The object enters Edit Mode.
  2. Press 2 for Edge Select. Click edges, Shift-click to add.
  3. Press U › Mark Seam (or Ctrl E › Mark Seam).
  4. Press A to select everything, then U › Unwrap.
  5. In the UV Editor, try Display Stretch, Average Islands Scale and Pack Islands.
  6. Optional: UV › Live Unwrap re-unwraps every time you change a seam.
  7. Scaled the object in Object Mode? Ctrl A › Scale first, then unwrap — otherwise the texture stretches.
