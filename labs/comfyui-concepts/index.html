MODEL ADAPTATION

A LoRA changes the model's behaviour.

A LoRA stores learned adjustments. Load LoRA applies them to a compatible model, and often its text encoder, before sampling.

What Load LoRA receives

MODEL + CLIP + LoRA file. It needs a compatible base checkpoint. Its outputs are modified MODEL and CLIP objects; the VAE passes separately from the checkpoint.

Checkpoint
MODEL + CLIP→Load LoRA
weight adjustments→Sampler + prompt encoder
use modified versions

The LoRA is not painted onto the finished image. It influences generation because the sampler uses the modified model and the prompt encoder may use the modified CLIP.

When would you use it?

LoRA: adapt appearance, a learned subject, or a visual concept, subject to the training and compatibility of the LoRA. Prompt: describe what you want using the existing model. A stronger LoRA is not automatically better.

STRUCTURAL GUIDANCE

ControlNet gives the sampler a guide.

It steers structure from a guide image, such as edges, depth, or pose. The result is still generated by the base model.

Three jobs that are easy to confuse

  1. Prepare a guide. Load an image and, if needed, run a suitable preprocessor to make an edge, depth, or pose map. A preprocessor may come from an extension.
  2. Load ControlNet Model. Choose a ControlNet model compatible with the base model and the guide type.
  3. Apply ControlNet. Combine the guide image and ControlNet model with the prompt conditioning. The modified conditioning goes to the sampler.

Apply ControlNet does not automatically extract edges, depth, or pose from an ordinary photo. A guide map is not the final image.

LoRA or ControlNet?

LoRA changes learned model behaviour. ControlNet adds guidance from an external image to conditioning. They can be used together: one can influence appearance while the other steers structure.
