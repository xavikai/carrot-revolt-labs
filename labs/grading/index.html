    KEY IDEAS

    Correct, then create

    First make the picture technically right (levels, white balance, matching). Then give it a look. Scopes keep you honest because your eyes adapt to any colour after a few seconds.

    Waveform
    Brightness of every column of the picture, 0 (black) to 100 (white). Parade: the same for R, G and B side by side.
    Vectorscope
    Colour only: angle = hue, distance from the centre = saturation. Skin lies near the skin tone line.
    Lift · Gamma · Gain · Offset
    Shadows, midtones, highlights and everything. The puck of each wheel moves the colour of that range; the dial below moves its level.
    Nodes
    Each node is a full set of tools. Serial nodes work one after the other: balance first, look later.
    LUT
    A look-up table: a fixed transform from input colours to output colours. Technical LUTs convert log to Rec.709; creative LUTs give a look.
    Secondaries
    A Qualifier keys a colour range, a Power Window keys a shape. The node only changes what is inside the key.
    IN DAVINCI RESOLVE

    Where things are on the Color page

    Everything in this lab has the same name in Resolve. The free version has all of it.

    1. Open the Color page (bottom bar). Show the scopes with Workspace › Video Scopes or the scopes button of the palette bar.
    2. Color Wheels palette: Primaries - Color Wheels mode for Lift, Gamma, Gain and Offset; Contrast, Pivot, Sat and Hue are in the bars above and below.
    3. Nodes: Alt S adds a serial node, Ctrl D disables the selected one. Right-click a node › LUTs to apply one.
    4. Qualifier palette: pick a colour in the viewer, refine Hue, Sat and Lum; Shift H highlights the key.
    5. Window palette: Circle, Linear, Polygon, Curve, Gradient; adjust Soft; the Tracker makes it follow the subject.
    6. Matching: right-click the viewer › Grab Still, then play it back from the Gallery with a split-screen wipe.
