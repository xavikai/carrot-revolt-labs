Where the edges go decides everything.

Edit meshes in a Blender-style Edit Mode. Read quads, triangles, n-gons and poles; keep shapes under Subdivision Surface with holding edges and creases; put edge loops where a joint bends; and build a clean retopology cage on a dense sculpt.

    BACK IN BLENDER

    Checking topology in Blender

    Blender has all these tools in Edit Mode (Tab). The lab uses small meshes so every change is easy to see.

    1. Select › Select All by Trait › Faces by Sides finds triangles (3, Equal To) or n-gons (4, Greater Than). Viewport Overlays › Statistics counts them.
    2. Connect Vertex Path (J), Dissolve (X) and Tris to Quads (AltJ) turn messy faces into quads.
    3. Loop Cut and Slide (CtrlR) adds holding edges; Edge Crease (ShiftE) keeps edges sharp without new geometry. Ctrl1–3 adds a Subdivision Surface.
    4. For deformation, test the mesh with the armature early: bend every joint to 90° and look for folds and collapse. The Armature modifier has Preserve Volume.
    5. Retopology: Snapping to Face Project (or a Shrinkwrap modifier), Fill (F), Smooth Vertices, and the Poly Build tool.
    6. Keep the final low poly all quads, with poles on flat areas and loops following the forms and the joints.
