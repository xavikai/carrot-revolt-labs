3DS MAX · CHARACTER ANIMATION TOOLKIT

Construeix el CAT rig.

Segueix la guia de construcció del curs amb els panells de 3ds Max: crea el CATParent, afegeix hubs i extremitats, col·loca els pivots a Front i Left, configura IK Targets, Up Nodes i gizmos, i prova el rig en Animation Mode.

Model 3D de pràctica (CC0)

CC0 és una dedicació al domini públic: es pot reutilitzar i modificar el model sense demanar permís. La malla és de Quaternius. Pots veure-la opaca o translúcida, amagar-la o importar un OBJ des del menú File.

Pràctica amb un personatge propi

Importa un FBX o OBJ a 3ds Max amb File › Import › Import. Comprova la posició neutra, l’escala i que la malla sigui adequada per deformar. Després segueix els mateixos controls CAT i Skin que has practicat aquí.

Els Universal Base Characters de Quaternius ofereixen models CC0 amb OBJ. També pots utilitzar els fitxers de pràctica d’Autodesk.
