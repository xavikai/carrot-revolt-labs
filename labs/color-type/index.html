    The same ideas in your tools

    The lab imitates Figma's panels. The numbers are the same you will find in Figma, Illustrator, InDesign or a browser.

    1. In Figma, a colour becomes a colour style or a variable; a variable collection can have modes (Light and Dark).
    2. Check contrast with a plugin (Stark, Contrast) or with the browser's developer tools. Simulate colour vision in Chrome DevTools › Rendering › Emulate vision deficiencies.
    3. For print, work in Illustrator or InDesign with the printer's profile (for example Coated FOGRA39) and turn on View › Proof Colors and Gamut Warning.
    4. Letter spacing in Figma is in % of the font size; in CSS it is letter-spacing in em. Line height 150% = line-height: 1.5.
    5. Build the type scale as text styles and use only those: no loose sizes in the file.
