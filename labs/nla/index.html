Actions become strips. Strips become a performance.

The NLA Editor (Nonlinear Animation) places whole actions in time and mixes them, like layers in a video editor. Push actions down into strips, sequence them, layer a wave over a walk, fade with Influence, repeat and scale cycles, and bake the result into one clip.

    FUNDAMENTALS

    The NLA Editor, piece by piece

    Read a tab before a stage, or come back when something is not clear. The examples on the Extrapolation and Blending tabs react to what you change.

    Action
    A data-block that stores the keyframes (F-curves) of an object or an armature: Walk, Jump… Its keys have their own frame numbers, independent of where it plays in the scene.
    Active action
    The one action an object plays directly, the one you edit in the Action Editor. In the NLA it is the orange row at the top, the action line.
    Strip
    A block in an NLA track that plays an action, or part of it, at a place in the timeline of the scene, with its own speed, repeats and mixing. It references the action: it does not copy the keys.
    Track
    A row of strips that never overlap. Tracks are layers: the ones above are mixed on top of the ones below.
    Stack
    All the tracks plus the action line. Blender evaluates it from the bottom up, at every frame.
    Push Down
    Turns the active action into a strip in a new track at the top of the stack. The action line is left empty.
    Stash
    Keeps the active action in a muted track called [Action Stash]: it is saved with the file but does not play.
    Tweak Mode
    Tab on a strip: its action opens in the Action Editor and you edit the keys themselves. Every strip that plays that action changes. Tab again to leave.
    Users · Fake User
    How many things use a data-block. An action with 0 users is not saved. The Fake User (F) is a user that never goes away.
    Slot
    Since Blender 4.4, the part of an action that belongs to one object. One action can animate several objects, one slot each.

    Why an action disappears

    A .blend file only keeps the data that something uses. Every action counts its users, and when you save, close and reopen the file, the actions with 0 users are gone. Animators lose work this way more than any other: an action made in the Action Editor, replaced by another one, and never pushed down, stashed or given a Fake User.

    Good habits

    1. Turn on the F of every action of a character as soon as you create it.
    2. Before you switch to another action in the Action Editor, Stash or Push Down the current one. New stashes it for you if nothing else uses it.
    3. Read the Browse Action list: an action with 0 and no F will disappear (the lab marks it with ⚠).
    4. Deleting a strip (X) or unlinking an action (✕) takes away a user, not the action. The action goes at the next save if nothing else uses it.
    5. In Blender's Outliner, Display Mode › Blender File lists every action and Orphan Data lists the ones with 0 users. File › Clean Up › Purge Unused Data deletes the orphans.

    Try it in stage 2, with File › Save & Reopen at the top left of the workspace.

      SAME KEYS AS BLENDER

      Shortcuts you can use here

      Keys go to the editor under the mouse, as in Blender: the same G moves strips in the NLA and keys in the Action Editor.

      LMB · ShiftLMB
      Select a strip (or a key) · add to the selection. Drag a strip to move it in time or to another track. Drag on empty space to box-select. Click a track name to make it the active track.
      G · S
      Move · scale the selected strips (type a number for an exact value; Enter or click confirms, Esc cancels)
      Tab
      Start / stop tweaking the action of the selected strip (Full Stack)
      ShiftA · ShiftT
      Add an action strip at the current frame · add a transition between two selected strips
      ShiftD · AltD
      Duplicate (with a copy of the action) · Linked Duplicate (same action)
      Y · X · H
      Split at the current frame · delete · toggle muting
      CtrlA · AltS · U
      Apply Scale · Clear Scale · Make Single User
      AltF · PageUp PageDown
      Swap two strips · move strips to the track above / below
      I
      Over the Influence field (Animated Influence on): insert a key of the influence
      A · AltA · Home · N
      Select all / none · frame all · show or hide the Sidebar
      Space · ← →
      Play / pause · previous / next frame (Shift jumps to the start / end)
      CtrlZ
      Undo · CtrlShiftZ redo
      BACK IN BLENDER

      The NLA in a real project

      This lab is a simplified Blender: one armature, six actions and the main NLA tools. Push Down, tracks, extrapolation, blending, influence and the Action Clip settings behave like Blender's.

      1. Open the Animation workspace and change one editor to Nonlinear Animation. Keep a Dope Sheet › Action Editor next to it.
      2. Animate each motion as its own action (New in the Action Editor) and give it a Fake User (shield icon) or Push Down / Stash it, so it is not lost when nothing uses it.
      3. Since Blender 4.4 an action has slots: one action can hold the animation of several objects. The Slot field next to the action (Action Editor header, Action Clip panel) says which part a strip plays. With one character, the slot has the object's name.
      4. Keep loops clean: key the first pose again at the end, then set the strip's Frame End one frame earlier. For walks that travel, animate them in place and move the character's root separately, because a repeated strip does not accumulate location.
      5. Layer corrections with Combine, fade with Blend In/Out or an Animated Influence, and check layers with Solo and the track checkboxes.
      6. For Unity, export each action as a clip (FBX › Animation › NLA Strips or All Actions), or Bake Action a mix into one action first. The Export Lab covers the FBX options.
