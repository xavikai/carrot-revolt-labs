# Default plaster bust

The Lighting Lab's `bust.bin` is a reduced, rotated and scaled version of
**Head (Sculpting) – Realistic by Dan Ulrich (CC0)** from the [Blender Studio
Human Base Meshes bundle](https://www.blender.org/download/demo-files/).
Blender Studio credits Dan Ulrich, Paul Kotelevets, Tonatiuh de San Julián and
Julien Kaspar. The [source STL and its CC0 1.0 declaration are on Wikimedia
Commons](https://commons.wikimedia.org/wiki/File:Head_(Sculpting)_-_Realistic_by_Dan_Ulrich_(CC0).stl).

`tools/convert-lighting-bust.py` documents the conversion and regenerates the
compact mesh with Blender 5.2. The source STL is deliberately not checked into
this repository; the derived mesh retains the same CC0 dedication.
