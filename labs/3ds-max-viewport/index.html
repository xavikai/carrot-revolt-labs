Four views, one scene. Your first steps in 3ds Max.

The basics of 3ds Max 2027: the four viewports and how to move around them, selecting and transforming with exact values, building objects in the Create panel and changing them in the Modify panel, and cloning, arrays and groups to organise a scene.

STAGE
    3DS MAX WORKFLOW

    The same keys as in 3ds Max

    This workspace follows the default 3ds Max 2027 layout and keyboard shortcut set. Shortcuts work while the pointer is over the Max window. Customize › Hotkey Editor lists them all.

    MMB · Alt+MMB · wheel
    Middle mouse button: pan. With Alt: orbit. The wheel (or Ctrl+Alt+MMB) zooms.
    Alt+W
    Maximize Viewport Toggle: one big viewport or the four.
    T F L P
    Top, Front, Left and Perspective in the active viewport.
    Z · CtrlShiftZ
    Zoom Extents Selected · Zoom Extents All.
    F3 · F4 · G
    Wireframe Override · Edged Faces · grid on and off.
    Q W E R
    Select Object, Select and Move, Rotate and Scale.
    Ctrl · Alt + click
    Add to the selection · remove from it. Drag on empty space for a region.
    H · CtrlA D I
    Select From Scene · select all, none, invert.
    F5 F6 F7 F8
    Restrict to X, Y, Z, or cycle the planes. A: Angle Snap (5°).
    F12
    Transform Type-In dialog. The X Y Z fields of the status bar do the same.
    Shift + drag · CtrlV
    Clone: Copy, Instance or Reference.
    Space · Delete · CtrlZ
    Selection Lock · delete · undo (CtrlY redo).
    IN 3DS MAX

    The same, in the real program

    The lab keeps to the tools a first week in 3ds Max needs. Everything has the name and the place it has in 3ds Max 2027, so you can find it again there.

    1. Start with File › New › New All and check Customize › Units Setup: metric, metres, for display and for the system unit.
    2. Click in a viewport to activate it, right-click to activate it without losing the selection. Alt+W maximizes it.
    3. Navigate with the middle button: pan, Alt to orbit, the wheel to zoom. Z frames the selection.
    4. Create from Create › Geometry › Standard Primitives. Name each object in the Name and Color rollout as soon as you make it.
    5. Edit parameters and add modifiers in the Modify panel. Give enough segments to what you bend or twist.
    6. Use Transform Type-In (F12 or the status bar) for exact positions, rotations and scales.
    7. Clone with Shift: Instance for repeated parts, Copy for independent ones. Tools › Array for patterns.
    8. Keep the scene tidy: Group, Freeze what should not move and Hide what is in the way.
