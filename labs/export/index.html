    KEY IDEAS

    What travels in an FBX

    An FBX carries objects with their transforms, meshes with normals and UVs, material names with image paths, armatures and baked animation. Everything else (modifiers, nodes, constraints, drivers) stays in Blender unless it is applied or baked.

    Axes
    Blender is Z up, Unity Y up. -Z Forward, Y Up and Unity's Bake Axis Conversion turn one into the other without leaving a −90° rotation on the object.
    Units
    1 unit is 1 metre in both programs. Model at real size and export with Apply Scalings FBX Units Scale so the object's scale stays 1.
    Apply (Ctrl A)
    Rotation and scale set in Object Mode live in the object. Applying them moves them into the mesh, so the engine gets 0 and 1.
    Origin = pivot
    The origin in Blender is the point Unity turns, scales and places the object around.
    Baked, not live
    Modifiers, procedural textures and IK controls do not exist in Unity: apply, bake or leave them out.
    Colliders
    Physics uses simple shapes, not the render mesh: primitives, or one convex object per part.
    BLENDER → UNITY 6

    A checklist for every export

    The names are the ones of Blender's FBX exporter and of Unity 6's Model Import Settings.

    1. Blender: real size in metres, Ctrl A › All Transforms (or Rotation & Scale), origin on the floor or on the hinge, the object at the world origin, normals facing out (Face Orientation).
    2. File › Export › FBX: Limit to Selected Objects, Object Types Mesh (+ Armature), Apply Scalings FBX Units Scale, -Z Forward, Y Up, Apply Modifiers, Smoothing Face.
    3. Characters: Only Deform Bones, no Add Leaf Bones, no Apply Transform; Bake Animation with only the actions you want.
    4. Textures: Path Mode Copy + Embed Textures, or copy the image files into the Unity project yourself.
    5. Unity, Model tab: Scale Factor 1, Convert Units, Bake Axis Conversion, Generate Colliders only for static scenery. Rig: Humanoid or Generic. Animation: Loop Time. Materials: Extract Materials.
    6. Colliders: primitives added in Unity, or _COL objects exported with the model and turned into convex Mesh Colliders without a renderer.
