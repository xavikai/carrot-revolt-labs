DRECERES DE 3DS MAX

Les mateixes tecles que a 3ds Max

Aquest lab fa servir el joc de dreceres per defecte de 3ds Max 2027. Funcionen amb el ratolí a sobre de la finestra de Max o de la Track View. El menú Customize › Hotkey Editor les mostra totes.

W E R
Select and Move, Rotate i Scale. Q torna a Select Object.
N
Auto Key. El botó, el Time Slider i la vora del viewport es posen vermells.
' · K
Set Key Mode i Set Keys: prepara la pose i desa-la quan vulguis.
/
Play / Stop. A 3ds Max, Espai és Selection Lock, no reproduir.
, .
Fotograma anterior i següent (o clau anterior i següent amb Key Mode).
Inici Fi
Go to Start i Go to End del rang de temps.
Ctrl+Alt + arrossega
Al Track Bar: botó esquerre canvia l'inici, el central desplaça el rang i el dret canvia el final.
Maj + arrossega
Copia claus al Track Bar i al Dope Sheet.
Supr
Suprimeix les claus seleccionades (Track Bar o Track View).
Ctrl+Z · Ctrl+Y
Undo i Redo.
H
Select From Scene: tria un objecte pel nom.
Alt+W
Maximize Viewport Toggle.
Botó central · Alt+central · Ctrl+Alt+central
Al viewport: desplaça (pan), orbita i fa zoom. La roda també fa zoom.
Gizmo
Arrossega un eix (es torna groc) per moure, rotar o escalar només en aquell eix; el quadrat entre dos eixos mou en el pla. Clic dret mentre arrossegues cancel·la.
Maj+V
Tools › Preview - Grab Viewport › Create Preview Animation: renderitza el viewport fotograma a fotograma i el reprodueix al Media Player (desa .webm o .png).
Out-of-Range
Botó del Track View o Edit › Controller › Out Of Range Types: Cycle, Loop, Ping Pong, Linear o Relative Repeat després de l'última clau.
QUÈ HAS APRÈS

Tres vistes d'una mateixa animació

01

Timeline

El Time Slider escull el fotograma. El Track Bar mostra les claus de l'objecte. Auto Key registra els canvis; Set Keys els desa quan ho demanes.

02

Curve Editor

L'eix horitzontal és temps i el vertical és valor. La inclinació de la corba indica la velocitat del canvi. Ajusta les tangents per accelerar i frenar.

03

Dope Sheet

Cada fila és una pista. Mou o duplica claus per canviar el ritme sense canviar-ne el valor. Les pistes de posició, rotació i escala es poden editar per separat.
