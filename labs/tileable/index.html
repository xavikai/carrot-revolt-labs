One small image, no end in sight.

A tileable (seamless) texture repeats without a visible edge. Use one in Blender with Repeat and the Mapping node, lay out UVs for it, make one from a photo in a Photoshop-style workspace with Offset, the Clone Stamp and the Healing Brush, keep every PBR map tiling, project it without UVs and hide the repetition.

    BACK IN THE REAL TOOLS

    Tileable textures in Photoshop and Blender

    The same steps as in this lab. Photoshop menus change little between versions; the Blender names are the ones in the Shader Editor and the UV Editor.

    1. Photoshop: crop a square (Crop Tool, 1:1 (Square)), then Image › Image Size to a power of two. Even out the light before anything else (a blurred, desaturated, inverted copy in Linear Light at 50 %, or a High Pass).
    2. Filter › Other › Offset with half the width and height and Wrap Around, then Clone Stamp (S) and Healing Brush (J) over the cross. Edit › Content-Aware Fill can help on big areas. Check with View › Pattern Preview.
    3. Make Roughness, Normal and Height from the finished tileable colour, or repeat every offset and every retouch on each map. Tools that make maps (Substance 3D Sampler, Materialize…) have a tiling option: keep it on.
    4. Blender: Image Texture node with Extension › Repeat; a Mapping node (CtrlT with Node Wrangler) sets the size. Or scale the UV islands: with a tileable texture they may go outside 0–1 and overlap.
    5. Same metres per tile on every island, no stretching, rows along U. Unwrap walls that meet as one strip so the pattern turns the corner.
    6. No good UVs: Texture Coordinate › Object + Projection › Box with some Blend. To hide the repeat, multiply a large Noise Texture over the colour and mix a second texture with a size that is not a multiple of the first.
