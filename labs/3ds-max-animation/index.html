    3DS MAX WORKFLOW

    Controls you can use here

    This teaching workspace follows 3ds Max's animation layout. Pick a helper in the viewport, set keys with Auto Key or Set Key Mode, then edit its controller in Track View.

    Viewport helpers
    Select Root, SS_Top, SS_Bottom or Rotation. Use W or Select and Move; E or Select and Rotate turns Rotation. Click again to confirm a transform.
    Auto Key / Set Keys
    Auto Key makes a key when you change a helper. In Set Key Mode, change the pose and click Set Keys before changing the frame.
    Time Slider / Track Bar
    Scrub the frame numbers. Select and drag keys to retime the bounce; switch to Track View – Dope Sheet for rows by helper and controller.
    Track View – Curve Editor
    Select keys in the Key Window. Use Smooth curve, Linear curve or Step curve, and adjust individual tangents. Drag a key or tangent handle to shape motion.
    Selected key
    The right panel shows its frame, value, curve type and tangent type. You can enter an exact frame or value there.
    CtrlA / Del
    Select every visible key / delete selected keys in this lab.
    Space / CtrlZ
    Play or pause / undo.
    IN 3DS MAX

    Rebuild the bounce in 3ds Max

    This lab simplifies the application to the controllers needed for one ball. In a Max scene, use named helper objects or a custom rig, then animate their Position, Rotation and Scale tracks.

    1. Create a ball and a helper hierarchy: Root for the path, SS_Top and SS_Bottom for deformation, and Rotation for rolling.
    2. Use the Time Slider to choose frames. Enable Auto Key to record changed transforms, or use Set Key Mode and Set Keys after posing.
    3. Open Track View – Curve Editor. Select the Z Position keys in the Controller Window; use smooth tangents near the tops and break/linear tangents at the contacts.
    4. Use Track View – Dope Sheet or the Track Bar to move keys closer together after each contact.
    5. Right-click the ball and choose Show Motion Paths to inspect spacing. Keep the ball above the floor while squashing and stretching.
    6. Match Y Rotation to X travel so the ball rolls without sliding.
