Time it. Give it weight. Squash it.

The bouncing ball, one principle at a time. Move its helpers in the Viewport, create keys with Auto Key or Set Keys, then shape movement in Track View – Curve Editor and adjust timing in the Track Bar or Dope Sheet.

    The same keys as in 3ds Max

    This workspace follows the default 3ds Max 2027 layout and keyboard shortcut set. Shortcuts work while the pointer is over the Max window or Track View. Customize › Hotkey Editor lists them all.

    Select and Move, Rotate and Scale. Drag a helper or its gizmo axis in the viewport; right-click while dragging cancels.
    N
    Auto Key: the button, the Time Slider and the viewport border turn red, and every change is keyed.
    ' · K

    , . · Home End

    IN 3DS MAX

    Rebuild the bounce in 3ds Max

    This lab simplifies the application to the controllers needed for one ball. In a Max scene, use named helper objects or a custom rig, then animate their Position, Rotation and Scale tracks.

    1. Build the rig used in class: ctrl_master and ctrl_pilota (shapes) for placement, path and rolling, squash_space with ctrl_top and ctrl_bottom (point helpers) for squash and stretch, and ball_Bone to deform pilota_Mesh. Freeze the transforms of the controls.
    2. Use the Time Slider to choose frames. Enable Auto Key to record changed transforms, or use Set Key Mode and Set Keys after posing.
    3. Open Track View – Curve Editor. Select the Z Position keys in the Key Window; use Auto tangents near the tops and Fast or broken tangents at the contacts.
    4. Use Track View – Dope Sheet or the Track Bar to move keys closer together after each contact.
    5. Turn on Trajectory in the Display panel to inspect spacing. Keep the ball above the floor while squashing and stretching.
    6. Match Y Rotation to X travel so the ball rolls without sliding.
    7. Check the result with Tools › Preview - Grab Viewport › Create Preview Animation (Shift+V) and play it in the Media Player.
